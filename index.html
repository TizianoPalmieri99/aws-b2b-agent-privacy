App in fase di sviluppo. Il collegamento API non è ancora attivo. Questa informativa descrive il progetto nello stato attuale e la pagina pubblica. Sarà aggiornata prima di attivare l'accesso ai dati LinkedIn.

1. Chi gestisce l'app

Tiziano Palmieri, Italia, gestisce AWS B2B Agent, un progetto destinato al supporto della propria attività professionale. Per domande sul trattamento dei dati: palmieritiziano99@gmail.com.

2. Ambito e stato del servizio

L'app è in preparazione per l'uso del solo titolare. Non è attualmente un servizio di accesso aperto ad altri utenti. Non è stato configurato un collegamento API a LinkedIn. La sola lettura di questa pagina non collega un account.

La fase iniziale prevista riguarda esclusivamente l'autenticazione tramite LinkedIn e la lettura dei dati di base autorizzati. Pubblicazione, commenti, messaggi, inviti e altre azioni sull'account restano disabilitati.

3. Dati e permessi del collegamento futuro

Attualmente l'app non recupera dati tramite le API LinkedIn e non riceve token di accesso. Per una prima fase è previsto di richiedere soltanto i permessi openid e profile. Questi consentirebbero di ricevere un identificativo dell'account, il nome, il riferimento alla foto del profilo e le informazioni tecniche presenti nella risposta di autenticazione, come scadenza e lingua, se disponibili. Non è previsto il permesso email.

Il flusso OAuth utilizza un codice di autorizzazione temporaneo e token tecnici. L'app non deve richiedere la password di LinkedIn né cookie di sessione. L'indirizzo email indicato in questa pagina è un recapito di contatto fornito dal titolare, non un dato recuperato tramite l'API.

4. Finalità e contatti

La finalità prevista per il futuro collegamento è riconoscere l'account autorizzato e verificarne il funzionamento. Nello stato attuale non avviene alcun trattamento di dati acquisiti tramite le API LinkedIn.

Chi scrive volontariamente al recapito indicato fornisce l'indirizzo email, il contenuto della richiesta ed eventuali allegati. Questi dati sono utilizzati per rispondere e gestire la richiesta, sulla base del legittimo interesse a dare seguito alle comunicazioni ricevute. Non inviare password o token. I dati non sono destinati a pubblicità, vendita o profilazione commerciale.

Prima dell'attivazione del collegamento saranno precisati i trattamenti effettivi e le relative basi giuridiche. L'autorizzazione tecnica OAuth non sostituisce questa valutazione.

5. Conservazione e sicurezza

Il progetto prevede un collegamento eseguito localmente sul dispositivo del titolare. Dati di autenticazione e token non devono essere pubblicati su GitHub, inseriti in chat, registrati nei normali log o conservati nei report del progetto.

Le comunicazioni inviate al recapito di contatto sono conservate per il tempo necessario a gestire la richiesta e gli eventuali obblighi di legge o esigenze di tutela dei diritti. Prima di attivare le API saranno descritte le modalità effettive di custodia dei token, accesso, conservazione e cancellazione dei dati. La durata dei token è distinta dalla conservazione dei dati.

6. Servizi esterni e hosting della pagina

Per il futuro collegamento, LinkedIn riceverà le richieste di autenticazione e le chiamate autorizzate e tratterà i dati secondo la propria informativa privacy.

Questa informativa è pubblicata su GitHub. L'eventuale versione web dedicata è ospitata su GitHub Pages. GitHub tratta dati tecnici delle visite, incluso l'indirizzo IP, per finalità descritte nella propria informativa privacy. GitHub ospita il testo pubblico, non i token del collegamento. L'infrastruttura di GitHub può comportare trattamenti fuori dallo Spazio economico europeo; le garanzie applicate sono descritte nella sua informativa, nella sezione sui trasferimenti internazionali. L'eventuale uso di altri servizi, inclusi servizi di intelligenza artificiale, sarà descritto prima di introdurlo nel trattamento dei dati recuperati tramite API.

7. Revoca e richieste sui dati

Dopo l'attivazione, l'accesso potrà essere revocato dalle impostazioni LinkedIn relative alle applicazioni o ai servizi autorizzati. La revoca impedirà il successivo accesso autorizzato; non cancellerà automaticamente eventuali copie già conservate localmente.

Per richieste di accesso, rettifica, cancellazione, limitazione, opposizione o portabilità, nei casi previsti dalla normativa applicabile, scrivere a palmieritiziano99@gmail.com. Resta possibile presentare un reclamo al Garante per la protezione dei dati personali.
